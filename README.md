Entry for the make.fun bounty [Make the best cooking game](https://make.fun/bounty/best-cooking-game-20261125-0137).

**Sizzle Rush** is an original top-down kitchen game. You are the chef on a
lunch-rush shift: tickets fly in on the order board, each with its own
countdown. Grab ingredients from the counter bins, grill the patty (and don't
let it burn), stack the dish on the assembly plate in the right combination,
then carry the finished plate to the serving window before the ticket runs
out. Fast serves build a combo; expired tickets break it. One shift lasts
150 seconds — how many dishes can you serve?

- Keyboard (WASD / arrows + E) and mouse (click to walk, click a station to use it)
- Order board with live ticket countdowns, grill with cook/burn timers, assembly plate with ready-to-serve glow
- Synthesised WebAudio sounds (sizzle, ding, coins) — no audio files
- Static files only: `game/index.html` runs offline in desktop Chrome, no network requests

Play it locally: serve `game/` with any static server (for example
`python3 -m http.server` inside `game/`) and open it in a browser.
